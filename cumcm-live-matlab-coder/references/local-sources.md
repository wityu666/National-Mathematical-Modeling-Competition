# MATLAB 本地来源、兼容性与禁用项

## 根目录与用途

根目录：

`$CUMCM_RESOURCE_ROOT/⑤Matlab学习资料及常用模型算法代码`

把 `CUMCM_RESOURCE_ROOT` 设置为包含七个编号资料文件夹的目录；未设置时按 `$HOME/Downloads` 理解。只把该目录用作私有、只读、clean-room 路径索引。不要把整个目录加入 MATLAB path，也不要直接运行下载案例或二进制。

## 盘点结果

- 约 3.5GB，`rg --files` 可见 69,325 个文件。
- 主要类型：41,932 `.m`、2,061 `.mat`、1,854 MEX、1,169 C、1,050 TXT、390 PDF。
- `2、MATLAB工具箱` 约 2.9GB、67,476 个文件；核心合集含约 172 个顶层工具箱。
- `6、按赛题类型划分的算法及MATLAB代码` 约 333MB、1,005 个文件，其中 268 `.m`、68 `.mat`、38 PDF、21 ZIP、21 RAR。
- 该赛题分类子集中有 51 个空 `.m` 文件；全目录有 116 个空 `.m` 文件。
- 赛题分类子集有 12 个 `.mexw32`、4 个 `.mexw64`，没有 macOS MEX；另含 Windows EXE/DLL。
- 赛题分类子集随机算法代码中没有发现 `rng(...)`，但有多处随机采样。
- 全目录包含混合来源的开源许可文件，但赛题分类子集只发现 1 个明显许可标记，不能视为整体可分发。

制作时的测试机检测到 MATLAB R2026a，但未运行下载案例，也未验证 Optimization、Statistics、Deep Learning 等工具箱许可证；每次赛时运行必须重新预检。

## 明确禁用

- 所有 `.mexw32`、`.mexw64`、DLL、EXE、MSI 和未知 MEX。
- `预测类赛题——灰色预测模型/灰色预测软件/Excel输入模板/注册码.txt` 及其软件。
- `2、MATLAB工具箱/.../150MATLAB工具箱- MatrixVB 4.5(含注册)` 整个目录。
- 路径名含 `破解`、`Crack`、`Keygen`、`注册码`、`补丁`、`注册版` 的任何材料。
- 约 119MB 的粒子群/遗传算法 ZIP、书籍 PDF、PPT、截图和没有明确分发许可的第三方工具箱。

不得通过改名、解压到别处或重编译来绕过禁用项。

## 赛时替代路线

| 旧案例依赖 | Clean-room 首选 | 回退 |
|---|---|---|
| 旧 LIBSVM/随机森林 MEX | `fitcsvm`、`fitcensemble`、`TreeBagger`，先验许可检查 | 简单线性/逻辑分类 baseline |
| Sheffield GA/旧 PSO 包 | 内置 `ga`/`particleswarm`，仅在许可可用时 | 贪心、局部搜索或可行 baseline |
| CVX/旧求解器二进制 | `linprog`、`intlinprog`、`quadprog`、`fmincon` | 简化模型并独立验约束 |
| 旧神经网络函数 | 当前版本内置模型并做交叉验证 | 回归、树或朴素预测 baseline |
| 随机单次切分 | `rng(seed,"twister")` 和显式索引 | 固定切分并报告限制 |

每条路线都要保存 `ver`、许可结果、`which -all`、`mexext`、seed、批处理命令、日志和冻结结果哈希。
