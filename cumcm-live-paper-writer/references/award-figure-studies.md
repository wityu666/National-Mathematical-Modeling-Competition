## 每篇论文的学习步骤

1. 确认文件、年份/题目（以原文为准）、总页数、实际查看范围与文件版本；能读取文件时记录 SHA-256。
2. 浏览正文全部含图页，建立图表清单，统计图型与子图数量；不得把未经查看的部分计入覆盖率。
3. 逐张查看图和相邻正文/题注，分析其解决的问题、数据或模型依据、布局、配色角色和可读性。复杂流程图需放大检查节点、条件和连线。
4. 从整篇层面分析图表在数据、模型、求解、结果与验证中的分布，以及总览图和局部图如何配合；记录缺点与不适用条件。
5. 将观察转成可迁移规则，注明适用任务、所需数据/模型、限制和在本题中的实现方式；只纳入已由页面支持的结论。

## 逐图记录模板

| 项目 | 记录内容 |
|---|---|
| 来源与位置 | 来源 ID、PDF 物理页、印刷页码（如有）、图号、题注 |
| 实际图型 | 图型、子图数量、布局及阅读顺序 |
| 图的作用 | 数据探索、模型解释、算法说明、结果回答或检验 |
| 丰富度来源 | 信息层次、互补证据、局部放大、组合方式 |
| 视觉处理 | 颜色角色、明暗层次、主次权重、留白、文字与图例 |
| 复杂流程结构 | 分组/泳道/共享模块/条件分支/反馈/局部展开及真实含义 |
| 正文关系 | 对应段落、公式、结论或模型；图与文字是否一致 |
| 可迁移方法 | 适用任务、输入要求、在新题中的原创实现 |
| 限制与问题 | 过密、小字、色差、误导尺度、缺乏数据等实际观察 |
| 证据与判断 | 页面直接观察 / 根据正文推断，分别注明依据 |

## 晋升为 skill 规则

学习记录完成后，再将有适用边界的发现加入图表手册或具体绘图 recipe，并链接来源记录与页码。多篇论文出现的相近做法可以归纳为共性规则；单篇有价值的做法标明来源与适用条件，不能直接推断为所有国奖论文的标准。

借鉴信息组织、视觉层级和表达方法；正式图的内容、节点、数据与布局从当前问题重新设计。参考图或页面截图只作为内部学习证据，不复制进待提交论文。
