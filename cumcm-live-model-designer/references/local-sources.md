# 本地模型资料索引与信任边界

## 根目录

把 `CUMCM_RESOURCE_ROOT` 设置为包含七个编号资料文件夹的目录；未设置时按 `$HOME/Downloads` 理解。

- Python：`$CUMCM_RESOURCE_ROOT/④Python学习资料及常用模型算法代码`
- MATLAB：`$CUMCM_RESOURCE_ROOT/⑤Matlab学习资料及常用模型算法代码`
- 教材课件：`$CUMCM_RESOURCE_ROOT/⑥数学建模必备教材及课件`
- 历届赛题：`$CUMCM_RESOURCE_ROOT/①历届赛题及获奖作品`

这些目录不是本届题面，也不是已验证代码仓库。本届官方规则、题面、附件、结果模板和实际数据具有更高优先级。

## 赛时引用规则

允许：

- 记录“哪类题通常有哪些 baseline、主模型和验证方法”。
- 读取少量文本以确认公式、输入输出和失败条件。
- 在新文件中按本届数据和现代库 API 独立实现，并写自己的测试。
- 在内部决策日志记录本地证据路径和抽象结论。

禁止：

- 复制获奖论文、教材、公众号资料的正文、代码、图表、结果或大段公式推导。
- 整包复制 Python/MATLAB 目录、PDF、PPT、字体、图片、数据集或工具箱进技能。
- 运行或分发 EXE、DLL、Wheel、MEX、宏、注册码、破解材料和未知压缩包。
- 将来源不明的示例结果当作本届实验结果。

## 兼容性提示

- Python 代码静态语法大多可解析，但仅 9 个文件有 `__main__` guard，许多脚本会在导入时读写文件或弹图。
- 旧示例包含已移除的 Pandas `ExcelWriter.save()` 和 Statsmodels `tsa.ARMA`，以及对未安装 `GLPK_MI` 的硬编码。
- MATLAB 赛题分类子集含 51 个空 `.m`；随机算法示例没有 `rng(...)`；部分脚本依赖旧神经网络接口。
- 赛题分类子集中的 MEX 为 Windows 格式，没有 macOS MEX；本机存在 MATLAB R2026a 应用不代表相关工具箱、许可证或旧案例可用。

因此，模型合同必须同时定义 baseline、现代内置实现、依赖预检和客观回退触发器。
